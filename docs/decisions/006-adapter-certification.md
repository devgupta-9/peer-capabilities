# ADR-006-adapter-certification: Adapter certification and support levels

## Status

Accepted, 2026-09-26. Not a claim of completed implementation.

## Context

The approved Phase-1 plan requires portable, auditable, safe incremental delivery.

## Decision

Track architectural support, implementation, platform certification and release support separately. Stage Technical Preview, Beta, GA.

## Alternatives

All 18 combinations before preview delays feedback without improving generic architecture.

## Consequences

Preview requires real Codex/Antigravity on declared combinations and deterministic third adapter, never two-agent installation dependency.
